## 这东西在哪

| 东西 | 路径 |
|---|---|
| 交件（4 张 JPG，300dpi，均 ≤10MB） | `submission/01-关.jpg` … `04-织.jpg` |
| 创作说明（PDF，490 字） | `submission/创作说明.pdf` |
| 版式定义（单一来源） | `data/plates.json` |
| 织纹合成（平纹/断纬/未织三态） | `src/weave.js` |
| 生图底版（已裁切去水印） | `plates/01-guan.png` 等 |
| 生图原片 | `plates/raw/`（不进仓库，只留档） |

## 重建

```bash
npm ci                 # playwright + fontsource
bash scripts/build.sh  # 字体 → 渲染 → JPG → 说明 PDF → 复验
```

单跑某一步：

```bash
node scripts/render.mjs --only 01     # 只出第 1 幅（含版式断言）
py -3 scripts/to_jpg.py               # PNG → 300dpi JPG
py -3 scripts/verify.py               # 对着交付物复验，退出码即结论
```

## 两条不能忘的规矩

1. **改文字必须重跑 `subset_fonts.py`**。少一个字就静默回落系统字体，图照样出，字形全变。
2. **`render.mjs` 是 fail-closed 的**：字体没加载 / 文字溢出 / 出安全区 / 织纹周期不对 /
   断纬区没读成竖条 / 版面上的数字对不上 `plates.json`，任何一条不过就不出图。

## 简章硬规矩（来自一级信源，见 `docs/01-SOURCES.md`）

- 作品名只能中文、≤20 字 → `不敢验`（3 字）
- 作品上不得出现作者、指导老师、学校名称 → 全图无署名，`verify.py` 会扫源文件
- 先免费存证再投稿；源文件需传网盘给永久链接 → 用户侧操作，见 `docs/05-SUBMISSION.md`
- 一件作品只能投一个类别；此前不得在其他赛事或公开刊物发表 → 本仓库私有
