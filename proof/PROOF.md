# 闸 B / 闸 C — 流程与能用

## 闸 B：断言先写，施工期靠它拦错

`scripts/render.mjs` 是 fail-closed 的：**任何一条断言不过，画面根本不会落盘**。六类断言：

| 类 | 拦的是什么 | 为什么必须有 |
|---|---|---|
| 字体真加载 | Noto Serif SC / Noto Sans SC 未加载 | 少一个字形就静默回落系统字体，图照样出、字形全变 |
| 溢出 | `[data-fit]` 的 scroll 超出 client | 引文/说明换行变了但框没变 |
| 安全区 | 任何 `[data-safe]` 越出 220px 边距 | A3 出血裁切会切字 |
| 字号下限 | < 24px（A3 300dpi 上约 2.0mm） | 印出来是糊的 |
| 文案一致 | 版面文字必须与 `data/plates.json` 逐字一致；作品名 1–20 汉字；不得出现作者/院校 | 改了数据忘了改版面 |
| 织纹 | lag-6 自相关（行/列均 >0.25）；断纬区横竖变化比 ≥1.45；偏离六色锚点 ≤34 | 织纹没排上、或断纬区没读成竖条——这两件事肉眼都能糊过去 |

另有一条「每厘米 118.11/6 ≈ 20 经」的换算断言，防止改了 cell 却忘了改版面上的「每厘米约二十经二十纬」。

## 闸 C：本机能用 + 全新 clone 能用

### 本机

```
$ node scripts/render.mjs
✓ 01 关  周期 0.68/0.81  调色板偏离 17.5  3508×4961  8011 KB
✓ 02 絮  周期 0.75/0.38  调色板偏离 26.2  3508×4961  8587 KB
✓ 03 桑  周期 0.89/0.91  调色板偏离 16.6  3508×4961  8934 KB
✓ 04 织  周期 0.78/0.31  调色板偏离 12.4  3508×4961  8160 KB

$ py -3 scripts/to_jpg.py
01-关.jpg  (3508, 4961)  300dpi  q94  4.88 MB
02-絮.jpg  (3508, 4961)  300dpi  q94  2.66 MB
03-桑.jpg  (3508, 4961)  300dpi  q94  5.70 MB
04-织.jpg  (3508, 4961)  300dpi  q94  5.32 MB

$ py -3 scripts/verify.py
0 项未过 / 共 40 项检查
```

`verify.py` 查的是**交付物**（JPG），不是渲染过程：尺寸 3508×4961、JFIF 300dpi、RGB、每张 ≤10MB、
lag-6 自相关、六色邻域占比、四张 sha256 互不相同、文字区墨量、创作说明是有效 PDF。

### 全新 clone

```
$ git clone <repo> _clone-bgy && cd _clone-bgy
$ npm ci && bash scripts/build.sh
0 项未过 / 共 40 项检查        ← 全部重建，40/40
```

**这一步抓到一个本机永远看不见的 bug**：说明 PDF 里的四张缩略图原本是我手工压进 `.tmp/thumbs/` 的，
而 `.tmp/` 不进仓库 —— 全新 clone 生成的说明 PDF 只有 175 KB（四张缩略图全没了），本机却是 618 KB。
图能出、断言也全过，只有比体积才看得出来。修法：缩略图改由 `scripts/to_jpg.py` 生成，因为它本来就要读那四张 JPG。
