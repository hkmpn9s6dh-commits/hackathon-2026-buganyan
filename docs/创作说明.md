# 不敢验

**组图四幅｜丝路图景 · 数字漫插创意类**

## 一、作品简介

取材于玄奘《大唐西域记》卷十二「瞿萨旦那国」：于阗求蚕种，东国禁而不与；公主「以桑蚕之子置帽絮中，既至关防，主者遍索，唯王女帽不敢以验」。新疆丹丹乌里克遗址出土的唐代木板画（46×12 厘米，藏大英博物馆）被多数学者认为画的就是这件事。

四幅各取一个动作：**关**：一行车队在关前解开行囊，唯冠未启。**絮**：冠拆开，里面只有丝绵与几十粒卵。**桑**：于阗城墙外长出的第一棵桑，沙丘上有驼队。**织**：水平双轴织机，经线绷紧，绸还没织完。

## 二、创作理念

丝路上真正流动的不是货物，是可以被复制的手艺。所以四幅都不是「画」的，是「织」的——每一幅都由近六百根经线、三百四十根纬线按平纹组织一上一下重排，缩小看是关、是冠、是桑、是机，放大看是布。

意义写在结构里：第二幅整幅不上机，只是絮；第四幅的绸到一半断了纬，只剩经线垂着——技术落地的那一刻，一匹布仍未完成。「不敢验」的那一寸，是整条丝路上唯一没被打开过的地方。

## 三、艺术表达

刻意避开敦煌符号与飞天。颜色只有六档：墨、深靛、石青、灰绿、丝白，另加一点朱。全组不出现正脸，只有冠、手、背影与剪影——既避开 AI 人脸的失真，也是这段故事的伦理姿态：她一路没有被看清。

## 四、创作工具与技术方式

三幅底版由文生图模型生成单色木刻稿，第二幅「絮」为纯程序绘制。随后以 Node + Canvas 按平纹组织重排经纬、量化到六色，无头浏览器渲染输出 A3／300dpi 的 JPG。全部文字由代码排版，字体子集随包，画面中没有一处 AI 生成的汉字。
