## 1 注册与存证（必做，简章硬规矩）

1. 打开 https://contest.cdec.org.cn/ → 注册/登录
2. 找到「作品存证」入口，把 4 张 JPG 与 1 个 PDF 上传做**免费存证**，拿到存证编号
3. 存证之后再投稿（顺序反了会被判无效）

## 2 源文件网盘链接（必做）

简章要求提交「作品源文件」的百度网盘**永久有效**分享链接。建议打包：

```
不敢验-源文件.zip
  ├─ plates/01-guan.png 03-sang.png 04-zhi.png   （生图底版，已裁切去水印）
  ├─ output/01.png … 04.png                      （3508×4961 原始渲染）
  ├─ src/weave.js  data/plates.json               （织纹合成与版式定义）
  └─ docs/创作说明.md
```

上传到百度网盘 → 右键「分享」→ 选「永久有效」→ 复制链接与提取码，投稿时粘贴。

## 3 投稿

1. 登录后进「第 21 届好创意 → 专项赛道 → 筑梦丝路·数智华章 AIGC 专项赛」
2. 类别选**丝路图景·数字漫插创意类**
3. 作品名：`不敢验`
4. 上传 4 张 JPG（按 01→04 顺序）+ 创作说明 PDF
5. 粘贴网盘链接
6. 检查三件事：**没有署名**、**没有指导老师**、**没有学校**（简章第四条）
7. 提交，**截图回执**（我要拿它把票改成 done）
